# 시의 여백

시를 쓰고, 다시 읽고, 퇴고하는 데스크톱 작업실입니다. 원고와 퇴고 기록은 내 컴퓨터에 보관합니다.

[설치 파일 내려받기](https://github.com/Boyacto/yeobaek-releases/releases/latest)

| 컴퓨터 | 받을 파일 | 설치 |
| --- | --- | --- |
| Mac · Apple Silicon(M1 이상) | `yeobaek-버전-mac-arm64.zip` | 압축을 풀고 앱을 응용 프로그램 폴더로 옮기세요. |
| Windows · x64 | `yeobaek-버전-windows-x64-setup.exe` | 설치 프로그램을 실행하세요. |

현재는 **테스트 배포**입니다. Mac은 개발 인증서로 서명했으며 Developer ID 공증 전입니다. Windows는 코드 서명 전입니다. 보안 경고가 나타나거나 컴퓨터의 보안 정책에 따라 실행이 제한될 수 있습니다. 보안 기능 전체를 끄지 말고, 실행이 막히는 경우 서명된 배포판을 기다려 주세요.

## 할 수 있는 일

- 내 시와 읽는 시를 보관하고 작가별로 찾아보기
- 여러 시를 탭으로 열어 쓰고 퇴고하기
- 제목·구절 메모, 받은 합평, 보류한 문장 기록
- 자동 기록과 이름을 붙인 판본 비교·복원
- 옵시디언 볼트와 연결하고 Markdown 파일로 저장
- MD·TXT·DOCX·PDF 내보내기, 인쇄
- 보관함 전체 백업·가져오기

## 업데이트와 원고

앱의 **앱 업데이트**에서 새 버전을 확인합니다. GitHub 로그인이나 별도 프로그램은 필요하지 않습니다. 쓰는 도중 강제로 재시작하지 않으며, 저장을 마친 뒤 업데이트합니다.

설치 파일에는 개발자의 개인 원고가 들어 있지 않습니다. 처음 설치하면 빈 보관함으로 시작합니다. 업데이트 서버로 원고·메모·백업을 보내지 않습니다.

다른 컴퓨터로 내 원고를 옮기려면 기존 앱의 **가져오기·백업 → 전체 백업**으로 파일을 저장한 뒤 새 컴퓨터에서 가져오세요. 앱 설치 파일만 보내면 내 원고는 전달되지 않습니다.

Windows CLI는 설치 폴더에서 PowerShell로 `./yeobaek.cmd help`를 실행합니다.

이 저장소는 설치 파일과 안내만 배포합니다. 개발 저장소는 별도로 비공개 관리합니다.
